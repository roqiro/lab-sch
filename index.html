使い方ガイド

培養・実験プロトコルを Day N 形式 で登録すると、開始日から絶対日付を自動計算します。Outlook に一括登録できる ICS ファイル や、プレゼン用の スライド画像 をワンクリックで出力できます。サーバー不要・ブラウザだけで動作します。

基本の流れ

  1. 1
    開始日とプロトコル名を入力
    左パネル「基本設定」で Day 0 の日付 とプロトコル名を入力します。作成者名・参照 SOP も任意で記入できます。
  2. 2
    ステップを追加・編集
    「ステップ追加」ボタンで行を追加し、Day 番号・タスク名・メモ（試薬など） を入力します。入力欄下の候補チップをクリックするとタスク名をすばやく入力できます。
  3. 3
    プレビューで絶対日付を確認
    右側「Outlook 登録前プレビュー」に各ステップの実施日が自動表示されます。土日はオレンジ で強調されます。
  4. 4
    ICS を書き出して Outlook に登録
    ヘッダーの「ICSを書き出す」を押すと .ics ファイルが保存されます。ダブルクリックするか Outlook にドラッグ&ドロップで一括登録されます。
  5. 5
    スライド用画像を保存（任意）
    ページ下部の「スライド用タイムライン」「カレンダー表示」から SVG または PNG でダウンロードしてスライドに貼り付けられます。

ステップ編集のコツ

  • •同じ Day に複数タスク を登録できます。各行に同じ Day 番号を入力してください。
  • •各行左端の ハンドルをドラッグ すると、同一 Day 内の順序を変更できます。Day をまたいで移動することもできます。
  • •行右端の コピーアイコン で同じ内容のステップをすばやく複製できます。
  • •候補チップは 過去に入力したタスク名 や保存済みプロトコルのタスクも学習します。

スライド用エクスポート

タイムライン（横矢印）
  • → ステップを横矢印の●でプロット
  • → 等間隔：コンパクトで見やすい（デフォルト）
  • → 日数比例：実際の間隔を視覚的に表現
カレンダー（7列）
  • → 月〜日の7列・月曜始まり
  • → タスクあり日をインジゴでハイライト
  • → 土曜：薄青 / 日曜：薄赤で色分け

SVG（ベクター形式・PowerPoint / Keynote / Illustrator で編集可）と PNG（高解像度 2x）の両方で保存できます。

保存・共有・バックアップ

  • •現在の内容を保存：名前をつけてブラウザ（localStorage）に保存します。「保存済みプロトコル」欄に一覧表示されます。
  • •共有リンク：スケジュールを URL に圧縮して埋め込みます。リンクを送るだけでチームと共有できます。
  • •JSON保存 / 読込：ファイルとして長期保管できるバックアップ形式です。「保存済み一括バックアップ」で全プロトコルをまとめてエクスポートできます。

よくある質問

データが消えてしまわないか？
入力内容は自動的にブラウザの localStorage に保存されます。ただし、サイトデータの全消去・シークレットウィンドウ使用時はリセットされます。定期的に「保存済みプロトコル」へ保存するか、JSON バックアップをお勧めします。
Outlook 以外のカレンダーでも使える？
ICS 形式は Google カレンダー・Apple カレンダー・Thunderbird など主要なカレンダーアプリに対応しています。
インターネット接続がなくても使える？
初回アクセス時のみ CDN からライブラリを読み込みます。HTML ファイルをローカルに保存して開く場合は、ブラウザキャッシュがあればオフラインでも動作します。
